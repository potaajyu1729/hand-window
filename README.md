# hand-window
カメラ越しに“空間を切り取る”体験を実現するWebアプリ

---

## 概要

このプロジェクトは、Webカメラと手のジェスチャー認識を使い、
現実の映像の中に「仮想の窓（ポータル）」を作り出すインタラクティブWebアプリです。

片手または複数の手でジェスチャーを作ることで、その領域だけ別の映像（異世界映像）が表示されます。最大4手を認識し、2手ずつフレームを作ります。余った1手は片手用の窓になります。

---

## 体験できること

- カメラ映像のリアルタイム表示
- MediaPipeによる手の骨格認識
- 最大4手に対応したウィンドウジェスチャー（2手ずつ、余りは片手）
- その領域だけに別動画を表示（ポータル表現）
- 「動画演出」の切り替え（オフ時も手のトラッキングを表示）

---

## 使用技術

- HTML / CSS / JavaScript
- MediaPipe Hands（手の骨格推定）
- Canvas API
- WebRTC（カメラ映像取得）

---

## 注意

- カメラアクセスが必要です
- HTTPS環境（GitHub Pagesなど）での実行を推奨
- PCブラウザ（Chrome推奨）での利用を想定
